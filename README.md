# C# Pong

Simple two-player Pong made with Godot 4 and C#.

- Left paddle: `W` / `S`
- Right paddle: computer opponent
- First to 10 points wins
- Press `R` to restart

Open the folder in the Godot .NET editor and run the project.

If Godot still shows a C# script loading error, use **Project > Reload Current Project**, then build once from the editor. Make sure you are using the **.NET** build of Godot, not the standard build.
